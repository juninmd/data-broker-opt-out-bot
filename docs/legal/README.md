# Legal Compliance Pack — Data Broker Opt-Out Bot

Este diretório contém a documentação jurídica e os modelos contratuais exigidos para conformidade com a **Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018)**.

## Arquivos Incluídos

1. **`DPIA_TEMPLATE.md`**: Relatório de Impacto à Proteção de Dados Pessoais (RIPD / DPIA) em conformidade com o Artigo 38 da LGPD.
2. **`DPA_BOILERPLATE.md`**: Acordo de Processamento de Dados (Data Processing Agreement) para Operadores do Bot, nos termos do Artigo 39 da LGPD.
3. **Gerador de Relatórios (Art. 18 LGPD)**: Módulo em Python localizado em `src/lgpd/` responsável por gerar os relatórios em formato PDF em resposta ao comando `/lgpd_report`.
